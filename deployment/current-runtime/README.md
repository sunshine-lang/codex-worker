# 当前部署脚本与源码校验

此处 runtime/、scripts/ 是 2026-11-14 当前服务器已安装脚本的字节级副本，保留其实际文件名与固定路径。
它们是**部署取证/复现资料，不是可直接在新机器运行的通用安装器**。可能读取管理员专用账户配置或执行沙箱恢复。

source-manifest.json 记录实际运行 EXE 的 SHA-256、全部应用模块的源码哈希、冻结代码对象比较结果，以及实际部署脚本哈希。
22 个 EXE 内应用模块和 worker_entry.py 代码对象与本仓库源码一致；另一个 service.py 是已安装但此 EXE 未使用的服务入口。
所用原始 task_tools.py 也与源码一致。

没有复制生产配置、Token、账号密码、Codex 登录文件、SQLite、任务输入输出或业务日志。
模型和登录由目标环境自行配置，本仓库不搬运任何账号认证状态。
