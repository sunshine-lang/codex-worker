Codex Worker 0.4.0 官方登录版：迁移到另一台服务器
================================================

1. 把这个 ZIP 复制到目标 Windows x64 服务器，完整解压到本地磁盘，例如 D:\CodexWorker。
2. 目标机必须已安装可调用的 Codex CLI，并在同一 Windows 用户下登录官方账号、能正常运行带工具任务。
3. 使用该用户的非提权桌面会话，普通双击本目录 CodexWorker.exe。
   不要从 ZIP 内直接运行，不要以管理员身份运行，也不要只复制一个 EXE。
   始终提权的内置 Administrator 会话会被拒绝；请使用普通用户的非提权会话。
4. 等待“服务已就绪”。首次会检查已有登录、沙箱、JSON 工具并启动后台服务。
5. 打开 Data\private\connection.txt，取得新 Worker Token；调用方使用目标服务器地址和新 Token。
6. 默认监听 0.0.0.0:8787。远程直连需由服务器管理方配置 Windows 防火墙、安全组/NAT；
   已有穿透客户端可转发到 127.0.0.1:8787。不要把 0.0.0.0 或 127.0.0.1 填成远程服务器地址。
7. 双击“运行一条测试翻译.cmd”，输入 YES 后执行一次真实翻译并下载结果，会使用当前账号额度。

日常：双击 CodexWorker.exe 启动或复用；查看状态用“查看状态.cmd”；停止用“停止服务.cmd”。
关闭启动窗口后 Worker 继续运行。Windows 用户须保持登录、主机不休眠且网络可用。

源码：source\CodexWorker-Source.zip，用于维护；运行 EXE 不需要先安装源码依赖。
设置：worker-settings.json，通常只需按实际访问方式调整端口/监听地址/显示用公网地址。
无需填写模型 API Key；沿用该用户 Codex 全局/所选 profile 的模型配置。
若配置仍选择第三方提供商，启动器会明确提示；它不会覆盖你的个人 Codex 配置。

出错：保留窗口错误代码和 Data\logs，按“使用说明.txt”处理。
沙箱、登录或原生工具检查失败时不会显示就绪；本包不自动修复或重置系统沙箱账户。
目标机的登录、沙箱、实际模型权限及真实翻译必须以目标机的检查结果为准。
